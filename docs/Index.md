# Шпаргалка по синтаксису Markdown

> **Назначение:** быстрый справочник для заметок в личной базе знаний  
> **Теги:** #markdown #синтаксис #шпаргалка

## Заголовки

Используются символы `#`. Максимум 6 уровней:

# H1 — главный заголовок
## H2 — раздел
### H3 — подраздел
#### H4 — ещё мельче
##### H5 — почти незаметно
###### H6 — совсем мелко

---

## Выделение текста

| Стиль | Синтаксис | Пример результата |
|-------|-----------|-------------------|
| Курсив | `*текст*` или `_текст_` | *текст* |
| Жирный | `**текст**` или `__текст__` | **текст** |
| Жирный + курсив | `***текст***` | ***текст*** |
| Зачёркнутый | `~~текст~~` | ~~текст~~ |

## Списки

### Маркированный список

- элемент 1
- элемент 2
- элемент 3

Или с другими маркерами:
* пункт A
* пункт B

### Нумерованный список

1. первый шаг
2. второй шаг
3. третий шаг

> Важно: нумерация в Markdown автоматическая. Пиши `1.` везде — рендер сам проставит 1, 2, 3.

## Блоки кода

### Инлайн-код (внутри строки)

Используй обратные кавычки: `console.log('Hello')`

### Блок кода (многострочный)

Три обратные кавычки + язык:

```javascript
function hello() {
  console.log('Hello, world!');
}
